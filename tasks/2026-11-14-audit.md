## For Mark, ranked (draft)

Status words: CONFIRMED means a run or the code proves it. SUSPECTED means the code suggests it and nothing was run.
"Checked by the Lead" marks the items the Lead has read at the file. The rest carry the subagent's evidence only.

### 1. The release gate

1. **CI skips 68 of 504 tests.** CONFIRMED from CI's own log. They read `reference/derived/_work-painting.png`,
   which is not tracked. The skipped cases include the street's triangle budgets. Proposed: commit a small fixture,
   or fail CI when a case skips.
2. **GitHub's Dependabot alerts and security updates are off.** CONFIRMED by the API. `.github/dependabot.yml:6-8`
   says they are on. `npm audit` lists 12 advisories (3 high: vite, zod, source-map-js), all in dev tooling.
   `npm audit fix` fixes 5 and moves vite 8.0.16 to 8.3.8, which changes every built file. So it needs a capture
   pass, not a blind merge. Mark's call: turn the setting on, and say whether to take the vite bump as a slice.
3. **`scripts/*.ts` is never type-checked and the `.mjs` files are never linted.** CONFIRMED. `tsc -b` covers `src`
   and `vite.config.ts` only. A one-off run found 14 errors (66 under strict), all in tests. None hides a weaker
   assertion (D read each). Proposed: a `typecheck:scripts` step in CI after the 14 are fixed.
4. **PR #44** (Dependabot, `actions/setup-node` 7.0.0 to 7.1.0) has been open since 2026-11-01, CI green, no Codex
   review. PR #43's Codex review found nothing.

### 2. A visitor can meet it

5. **A right or middle click in the street counts as a tap.** CONFIRMED in code, checked by the Lead.
   `src/scene/StreetWalk.tsx:567-584` never reads `e.button`. `StreetGrass.tsx:236` does. On Windows a right click
   sends Vincent walking or toggles his walk. `useTouchInput.ts` and `usePortalPointer.ts` have no button test
   either. The fix is one line in each.
6. **One failed texture blanks the whole page.** CONFIRMED in code (A1). `PaintingFlowSky3D.tsx:868-873` and
   `Village.tsx:26` load through `useTexture`, which throws. Only the street has an error boundary.
7. **The cypress has no failure path for the painting.** CONFIRMED in code (C-05). `BrushCypress.tsx:86` passes no
   `onError`. A failed load makes the opening and the way back each wait 15 s.
8. **The lighter view's offer fires about 4 fps late.** CONFIRMED by a run (A2). drei's monitor counts n frames
   over n − 1 intervals. A phone at 26 to 29 fps is under the 30 fps bar and gets no offer.
9. **At stop 4 a tap on Vincent does nothing, and a phone has no way back along the lane.** CONFIRMED by a run
   (B2, `streetWalk.ts:84,128`). The behaviour wanted is Mark's call.
10. **Paused and off the lane, the wheel is swallowed.** CONFIRMED by a run (B3, `StreetWalk.tsx:663,684`).
11. SUSPECTED, not run: the reduced-motion caption sits under the phone's wrapped dock (A3, `index.html:126`).
    A throw inside `useImageData`'s `onload` never calls `onError` (A4, `useImageData.ts:25-33`). Cmd+Arrow on a
    Mac leaves the arrow held (B4, `StreetWalk.tsx:536`). A browser frame cap reads as a slow device (A5).
